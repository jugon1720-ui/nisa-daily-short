Privacy Policy

Last updated: 2026-11-23

NISA Daily Short Uploader ("the App") is a personal tool used only by its developer to upload videos to the developer's own YouTube channel. The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Information the App accesses

  • An OAuth 2.0 access/refresh token for the scope youtube.upload, granted by the channel owner.
  • The App does not access, collect or store any other Google user data, any YouTube viewer data, or any personal information of third parties.

How information is used, stored and shared

  • The token is used only to call videos.insert to upload videos generated by the App to the owner's own channel.
  • The token is stored only on the owner's local computer, in a file readable only by the owner. It is never sent to any server other than Google's.
  • No information is shared with, sold to, or disclosed to any third party.
  • The App does not use cookies or any tracking technology.

Revoking access / deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the local token file removes all data held by the App.
