NISA Daily Short Uploader

NISA Daily Short Uploader is a personal, non-commercial tool run by a single YouTube creator on their own Mac. Every morning it creates a ~30-second vertical video (YouTube Short) that shows the recent closing-price trend of one popular stock or index (e.g. S&P 500, Nikkei 225, Toyota) and uploads it to the creator's own YouTube channel only, scheduled to be published at 7:30 JST.

How it uses YouTube API Services

  • Scope: https://www.googleapis.com/auth/youtube.upload only.
  • API call: videos.insert — about one upload per day (≈1,600 quota units/day).
  • Only the channel owner signs in. The tool is not offered to any other users and is not a public service.
  • No YouTube data is read, stored, analysed or shared.
